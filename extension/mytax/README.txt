Мой налог: кассовые чеки для ИП (НПД) v4.1.0
Чистый PHP без Node.js

Возможности:
- Автоматическое создание кассового чека в «Мой налог» (API lknpd.nalog.ru)
  при переводе заказа в статус «Оплачен».
- Отправка покупателю письма с QR-кодом чека ФНС.
- Лимиты создания чеков (глобальный и на один IP).
- Проверка соединения с «Мой налог» по ИНН/паролю прямо из админки
  (кнопка «Проверить соединение» на странице настроек модуля).
- Автоповтор неудавшихся чеков через cron: scripts/mytax_retry.php.
- QR-код кассового чека на странице заказа в АДМИНКЕ: в блоке «Метод оплаты»
  администратор видит QR-код чека ФНС, номер чека, сумму, дату и ссылку
  «Открыть чек ФНС» (требует правки файлов админки, см. patches/admin-order-qr/).
